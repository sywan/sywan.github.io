編輯網站內容

修改首頁資料、各卷書研讀內容或延伸閱讀，儲存後由 GitHub Pages 自動發布。每次儲存都會留下 GitHub 版本紀錄。

連接 GitHub

請使用僅授權 sywan/sywan.github.io、具有 Contents: Read and write 權限的 fine-grained Personal Access Token。憑證只留在此分頁記憶體；關閉或重新載入後需再次輸入。

在 GitHub 建立 7 天 Token ↗查看／撤銷既有 Token ↗

在 GitHub 登入並完成必要驗證後，請確認 Resource owner: sywan，選 Only select repositories → sywan.github.io，並確認 Contents: Read and write。Token name 可用簡短名稱加日期，例如 SYWAN Editor 20261122；下次只更換日期，名稱長度不會增加。產生後請複製 Token 文字；Token 清單可查看名稱與狀態，但無法取回文字。若不保存文字，下次就要再建立一把；不用的 Token 可從清單撤銷。

「新增筆記與資源」適用於所有書卷，可寫中英文內容或加入連結；「卷書內容」可編輯使用通用版型的 65 個書卷頁面。

上傳 PDF 到本卷書

先選擇 PDF 並上傳，再按「儲存並發布」，就會建立對應的延伸閱讀連結。單檔上限 10 MB。

此編輯器只有持有倉庫寫入權限的 GitHub Token 才能提交變更。提交後通常需要一小段時間才會出現在公開網站。
