連接 GitHub

請使用僅授權 sywan/sywan.github.io、具有 Contents: Read and write 權限的 fine-grained Personal Access Token。憑證只留在此分頁記憶體；關閉或重新載入後需再次輸入。

在 GitHub 建立 7 天 Token ↗查看／重新產生既有 Token ↗

在 GitHub 登入並完成必要驗證後，請確認 Resource owner: sywan，選 Only select repositories → sywan.github.io，並確認 Contents: Read and write。Token name 可用簡短名稱加日期，例如 SYWAN Editor 20261122。產生後請立即複製 Token 文字；GitHub 不會在詳細頁重新顯示它。若沒有保存，開啟上方既有 Token 清單，點選該項目後由您按 Regenerate token，複製新字串貼到下方；舊字串會失效，但可沿用同一筆 Token 的名稱與倉庫設定。
